# Simulado SAEP 2026

Repositório de apoio aos estudos para o SAEP 2026. O material disponibilizado inclui um arquivo PDF de simulado, organizado na pasta `pasta simulado/`.

## Material

- [Simulado em PDF](pasta%20simulado/Simulado.pdf)

## Como utilizar

Abra o PDF e resolva as questões como prática de revisão. Utilize os materiais oficiais do curso e as orientações dos professores como referência para corrigir dúvidas.

## Objetivo

Organizar materiais de estudo e apoiar a preparação para a avaliação SAEP.
